# Event-Platform (DevPulse)

A premium, dark-themed AI & Microservices workshop registration platform. Built for developers, architects, and tech leads.

## Features
- 🚀 **Next.js 14 App Router** - High-performance React framework.
- 💳 **Stripe Integration** - Test mode payments and checkout simulation.
- 🔐 **OAuth 2.0 Authentication** - Secure login via GitHub and Google using NextAuth.
- 🎭 **Role-Based Access Control** - Distinct User and Admin dashboards.
- 📧 **Automated Receipts** - In-app HTML email dispatch with QR codes.
- ✨ **Modern UI/UX** - Tailwind CSS, glassmorphism, and smooth scroll-reveal animations.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Tech Stack
- React / Next.js
- Tailwind CSS
